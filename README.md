# LovableInifity

## Mini e-book: Geladinhos Gourmet

Este projeto contém um mini e-book de **2 páginas**, em português.

- **Página 1:** capa com identidade visual tropical.
- **Página 2:** receita de morango cremoso, ingredientes, modo de preparo e dicas para venda.

**[Abrir e-book (HTML)](./ebook/index.html)**

Para salvar como PDF, abra o HTML no navegador e clique em **Salvar em PDF / Imprimir**.

O material pode ser editado e expandido com novas receitas.
